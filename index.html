Firebase Setup Required

Follow these steps once to enable sync across all your devices.

Step 1 — Create a Firebase Project

Go to console.firebase.google.com → Click Add project → Name it daily-manager → Disable Google Analytics (not needed) → Click Create project.

Step 2 — Register a Web App

In your project, click the </> Web icon → Name it daily-manager-app → Click Register app. You'll see a firebaseConfig object — copy it.

Step 3 — Enable Firestore Database

In the left menu → Firestore Database → Create database → Choose Start in test mode → Pick any region → Click Enable.

Step 4 — Enable Google Sign-In

Left menu → Authentication → Get started → Click Google → Toggle Enable → Add your email as support email → Save.

Step 5 — Add Authorised Domain (for GitHub Pages)

In Authentication → Settings → Authorised domains → Click Add domain → Enter yourusername.github.io (replace with your actual GitHub username).

Step 6 — Paste Your Firebase Config Below

Paste the firebaseConfig object you copied from Step 2. It looks like the example below.

Your config is saved in this browser. You only need to do this once per device.
